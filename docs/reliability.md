# Browser reliability

The current prototype uses Jev Ultrafast for routine observation and actions, with full Browser Use 0.13.10 recovery on the same session. Text clarification handles ambiguity; unlabeled fields and visual or unsupported controls can use the visual agent. Ordinary repairs return to Jev. Visual subtasks retain their images and history until resolved or explicitly handed back. It is a standalone repository with upstream attribution.

The repeated JFK–SFO round-trip search (November 12–16, 2026, one adult, economy, nonstop) passed independent date, airport, passenger, cabin, filter and visible-fare checks in **4/4 runs at 9.1–12.2 seconds** (median 10.2 seconds). The previous full Browser Use demo took **148.7 seconds**. These timings cover the browser engine after initial browser/page startup; the earlier engine also generated a prose answer, while the hybrid leaves the final answer to the invoking assistant using saved page evidence. A final run through the installed skill, using its default engine, also passed in **8.5 seconds**. This is one real workflow, not a general website speed claim.

The final hybrid passed **12/12** original MiniWoB++ cases with a **1.9-second median**, and **20/20** broader cases on seed 88202 with a **2.7-second median**. Earlier development runs scored 18/20 and 19/20; those failures led to visual-handoff and unlabeled-field fixes. The broader families and earlier seeds informed development; seed 88202 had not been used to tune the hybrid before the final run. Picture copying, sliders and custom dropdowns passed. Detailed pictured-pattern tasks still took approximately 56–70 seconds. Separate headless fixtures passed shadow DOM, cross-origin frames and new tabs; the latest new-tab fixture took 1.7 seconds. These adapted local subsets do not establish SOTA, an official leaderboard score, or arbitrary-site reliability.

The pinned upstream grader, 500×700 viewport, 40 action attempts and 120-second episode limit remain fixed. Success requires terminal state and raw reward exactly 1; model completion claims do not pass. The harness rejects episode resets. The agent uses observed controls and screenshots, not hidden grader answers. Raw traces, failures and model usage remain local and out of Git. A provider-billing precondition observed during testing now triggers inference-only provider rotation. Native desktop coverage remains limited to historical TextEdit smoke tests; OSWorld was not run.
