# Browser reliability

The default browser engine uses full Browser Use 0.13.10 for observation, execution, screenshots, tabs and frames, with Jev for simple decisions. The accepted configuration uses Fireworks Kimi K3 for recovery, DeepSeek V4.1 Flash for field text, and GLM-5.3 Flash for focused image reading. Keyboard controls, dragging, custom dropdowns and magnified image inspection are available. The repository retains its TypeSafe fork history; the previous narrow engine remains available with `--engine ultrafast`.

After an initial **33/40**, the new configuration passed **40/40** development cases and **20/20** cases on a newly frozen seed across the same 20 MiniWoB++ task families. Median end-to-end times were **9.3 seconds** and **10.7 seconds**. The original 12-task comparison also passed **12/12** (12.3-second median in the final rerun). Picture copying, sliders and custom dropdowns passed, but detailed picture cases still took approximately 67–95 seconds. Separate development checks passed six additional drag/slider tasks and local shadow-DOM, cross-origin-frame and new-tab fixtures. These are adapted local subset results, not a SOTA claim, official leaderboard score or estimate of success on arbitrary websites. Task families informed development; only the new seed was unseen.

The pinned upstream grader, 500×700 viewport, 40 action attempts and 120-second episode limit remain in place. Success requires terminal state and raw reward exactly 1; partial credit and model completion claims do not pass. The harness detects document and same-document episode resets. The agent receives observed UI and screenshots; arbitrary JavaScript, filesystem access and raw DOM searches that expose scripts are excluded. Raw traces, model usage and failed experiments stay local and out of Git; only this summary and the reproducible protocol are published. Faster configurations were tested but not selected when accuracy regressed. Native desktop coverage remains limited to historical TextEdit smoke tests; OSWorld was not run.
